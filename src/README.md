# Tic Tac Toe Game (Java)

A simple console-based Tic Tac Toe game implemented using Java.
This project was created to practice core Java concepts and basic game logic.

## Features
- Two-player game (X and O)
- Input validation
- Win and draw detection
- Console-based board display

## Concepts Used
- Arrays
- Loops
- Conditional statements
- Methods
- Exception handling
- Scanner class

## How to Run
1. Clone the repository
2. Open the project in IntelliJ IDEA (or any Java IDE)
3. Run the `TicTacToe.java` file

## Sample Output
The program displays a 3x3 board and asks players to enter a slot number (1–9) to place their mark.
